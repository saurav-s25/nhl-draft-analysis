# nhl-draft-analysis

## Project Goal
Analyze historical NHL draft data using SQL and Python to evaluate drafting trends, player value and the teams that have performed the best in drafts overall.

## Tools
- SQL 
- Python
- Git
- GitHub
- Excel

## Dataset
Historical NHL draft data including year,overall_pick,team,player,nationality,position,age,to_year,amateur_team,games_played,goals,assists,points,plus_minus,penalties_minutes,goalie_games_played,goalie_wins,goalie_losses,goalie_ties_overtime,save_percentage,goals_against_average,point_shares.

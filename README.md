# nhl-draft-analysis

## Project Goal
Analyze historical NHL draft data using SQL and Python to evaluate drafting trends, player value and the teams that have performed the best in drafts overall.

## Tools
- SQL 
- Python
- Git
- GitHub
- Excel

## Dataset
Historical NHL draft data from https://www.kaggle.com/code/mattop/nhl-draft-player-analysis-1963-2022
